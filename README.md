# Warehouse Picker Productivity & Incentive Analytics Dashboard

## 📌 Project Overview

This project is an Excel-based analytics dashboard designed to analyze warehouse picker productivity, accuracy, shift performance, and incentives.

The project uses a simulated warehouse operations dataset and demonstrates how Excel can be used to transform raw operational data into meaningful performance insights.

## 🎯 Objectives

- Measure picker productivity using Pick Rate.
- Analyze picking accuracy using Error Rate.
- Compare Morning and Evening shift performance.
- Calculate incentive earned per working hour.
- Identify top-performing pickers.
- Create a management-friendly Excel dashboard.

## 📊 Dataset

The dataset contains 50+ simulated warehouse operational records.

Key fields include:

- Date
- Picker ID
- Picker Name
- Shift
- Orders
- Items Picked
- Working Hours
- Errors
- Incentive

## 📈 Key KPIs

The dashboard calculates:

- Total Orders
- Total Items Picked
- Average Pick Rate
- Average Error Rate
- Incentive per Hour
- Performance Score
- Performance Rating
- Top Performer

## 📊 Dashboard Features

The dashboard provides analysis of:

- Picker-wise productivity
- Picker-wise accuracy
- Shift-wise productivity
- Total orders and items processed
- Incentive performance
- Top-performing picker

## 🧮 Performance Methodology

Picker performance is evaluated using both productivity and accuracy.

The Performance Score combines:

- 70% Productivity
- 30% Accuracy

This approach avoids evaluating workers only by the number of items picked and considers accuracy as well.

## 🔍 Key Business Questions

This project helps answer questions such as:

1. Which picker has the highest productivity?
2. Which picker has the lowest error rate?
3. Which shift performs better?
4. Who is the top overall performer?
5. How much incentive was generated?
6. Which pickers may require performance improvement?
